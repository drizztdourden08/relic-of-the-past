# Code notes

The code carries no comments, so the facts a reader cannot get from the code live here. There is one page per package or app area, in the layout of the repository, and each heading inside a page is the path of the file or folder it explains.

Add a note to the page of the package or area that holds the file, under a heading with the file path from the repository root. When a file moves, move its heading with it. When a file is deleted, delete its note.
