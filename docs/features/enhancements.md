# Visual Enhancements

Optional graphical improvements that go beyond the original SNES presentation.

---

## Edge Effect

When the game runs in an aspect ratio that doesn't fill the window (e.g., 4:3 on a 16:9 screen), the empty space on the sides would normally be black bars.

The **edge effect** fills this space with a mirrored and blurred version of the game border, creating a seamless, immersive extension of the scene. The effect animates in real-time as the game scrolls.

- Eliminates black bars without stretching the game image
- Subtle blur prevents the mirrored edges from being distracting
- Can be disabled in Profile Settings → Display if you prefer black bars

---

## Interior Background

In the original game, the area outside house interiors renders as a brown/black void. The **interior background** enhancement replaces this with a dark, clean background that's easier on the eyes and less visually jarring.

- Only applies inside buildings and caves
- Does not affect gameplay
- Can be toggled in settings
