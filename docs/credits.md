Full credits are available in-app via Menu → **Credits**.

---

## Technology

- **Game Engine:** zelda3 C port compiled to WebAssembly via Emscripten
- **Desktop Shell:** Electron
- **UI Framework:** React with TypeScript
- **Build System:** electron-vite + electron-builder
- **Asset Extraction:** Custom TypeScript pipeline (replaces the original Python scripts)
