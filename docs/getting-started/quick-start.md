# Quick Start

Get playing in about five minutes. You'll need your **own** legally obtained *A Link to the Past* ROM
— the app ships no game data.

## 1 · Install

Download the latest build for your platform from the
[**Releases**](https://github.com/drizztdourden08/relic-of-the-past/releases) page (Windows portable
or installer `.exe`, macOS `.dmg`, Linux `.AppImage`/`.deb`) and launch it. Details:
[Installation](installation.md).

## 2 · Import your ROM

Title bar → **Data** → **ROMs** → **Import ROM**, and pick your `.sfc`/`.smc`. The app validates the
checksum and **extracts the assets locally** (a few seconds, no Python needed). More:
[Importing a ROM & Assets](importing-a-rom.md).

## 3 · Create a profile

**Create Profile** → name it, pick the ROM, choose a language (optionally an MSU-1 music pack). A
profile is an isolated container for saves, settings, and controls. More: [Profiles](../user-guide/profiles.md).

## 4 · Play

Hit **Play**. The game runs in the app window.

| Action | How |
|--------|-----|
| Reveal title bar | hover the top edge (auto-hides in-game) |
| Menu | hamburger icon or `Escape` |
| Quick save | hold the configured button (default: Select) — [Save States](../user-guide/save-states.md) |
| Mute | speaker icon in the title bar |
| Open a widget | Menu → Widgets ([overview](../widgets/overview.md)) |
