# v0.8.1 — First Public Build

**Released:** May 2025

The first packaged release of Relic of the Past. The app is fully functional and playable, with extensive quality-of-life improvements over the original PC port.

> **Important:** This application does not contain any copyrighted material. You must provide your own ROM file.

---

## What's Included

### Core Architecture
- Electron + React + WebAssembly — the original C port compiled to WASM, wrapped in a modern desktop app
- No Python required — asset extraction rewritten entirely in TypeScript
- Cross-platform builds: Windows, macOS, and Linux
- Profile system — isolated containers with their own ROM, language, MSU pack, save data, settings, and control bindings

### Game Settings
- All original PC port settings exposed in the UI (no more .ini editing)
- Aspect ratio options including 3:2
- Window modes: fullscreen, borderless, windowed with autofit/stretch
- FPS display toggle

### Visual Enhancements
- Edge effect — mirrored & blurred animation on world borders (no black bars)
- Interior background — dark background inside houses instead of brown void

### Audio
- Full MSU-1 support with in-app import and management
- Independent music, SFX, and master volume controls
- Mute toggle in title bar

### Save System
- Auto-save with configurable timer + save-on-quit
- Quick saves — slide-down UI showing all slots, configurable hold duration
- Named saves — labeled saves without shortcut risk of accidental overwrite
- Save state screenshots — visual preview of each slot

### HUD
- Choice between original and enhanced HUD overlay
- Enhanced HUD respects aspect ratio for proper placement
- Smoother heart and magic meter animations
- Game sprites extracted and rendered as React overlay

### Haptics
- Vibration events: sword swings, hookshot impacts, damage, boss kills, locked doors, item pickups, explosions, pit falls
- Per-event toggle in settings
- Supported on Switch Pro, Xbox, PlayStation, 8BitDo, and more

### Input
- Supported: Switch Pro (v1 & v2), GameCube wireless, Xbox, PlayStation (DS3–DualSense), 8BitDo, keyboard
- Full rebinding of any action to any key, button, or axis
- Built-in input calibration tool (byte inspector, vibration tester, input recording)
- Controller icon sets for all supported devices

### Widgets
- Dock to any edge or float freely, resizable, adjustable transparency
- Inventory Tracker — all owned items in configurable layouts
- Checks Tracker — 257 checks with status, grouping, filtering
- Cheats — give items, fill bottles, adjust health/magic/rupees/ammo
- Logs — real-time app log viewer

### Auto-Update
- Built-in update checking on startup + manual check from menu
- Supported on installer (NSIS), macOS, AppImage, and .deb builds
- Portable Windows build does not support auto-update

## Known Limitations

- macOS and Linux builds are untested
- No code signing — OS may warn on first launch
- Auto-update requires the repository to be public (currently private)

## Getting Started

1. Download the appropriate file for your platform
2. Launch the app
3. Import your ROM via Menu → Data → ROMs
4. Create a profile and play

See [Getting Started](../getting-started.md) for detailed instructions.
