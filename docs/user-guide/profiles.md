# Profiles

A profile is a self-contained setup for the game. Each one keeps its own:

- ROM and language
- Save data of every kind
- Display, gameplay, and audio settings
- Control bindings
- MSU music-pack choice

## Creating a profile

1. Open the title-bar menu → **Data** → **Profiles**.
2. Choose **Create Profile** and give it a name.
3. Pick a ROM (import one first if you haven't).
4. Choose a language.

## Using a different profile

There's no live profile switch while you're playing. To use another profile, stop the game, open the title-bar menu → **Data** → **Profiles**, and pick or create one there. The app remembers the profile you used last and reopens it the next time you launch.

## What profiles are good for

- **Casual vs. speedrun:** different bindings and HUD for each.
- **Different languages:** an English profile and a French one sharing the same ROM.
- **MSU experiments:** try music packs without touching your main setup.

## Isolation

Profiles never affect each other. Settings, save files, quick saves, and auto-saves all stay within the profile they belong to.

## Deleting a profile

Deleting a profile removes its saves, settings, and bindings. The imported ROM stays, since ROMs are shared across profiles.
