# Controls

The **Controls** tab is where you set up how you play. It has three areas: your input profiles on the left, the binding editor in the middle, and your connected devices on the right.

## Input Profiles

An input profile is a saved control layout. Bindings are stored per profile, so each one can have its own setup. You might keep one profile for keyboard play and another tuned for a controller.

From the profile list you can create a new profile, rename it, duplicate an existing one as a starting point, delete it, and reorder the list. Activate a profile to make its bindings the ones in effect.

## Game Controls

This is the main binding table. Each row maps an SNES button to its in-game action and shows the current binding, either a keyboard key or a gamepad input. A row reads **Unmapped** when nothing is bound to it.

To rebind, click a row and press the key or button you want. You can also clear a binding to leave the action unmapped.

The SNES buttons and what they do in game:

| Button | Action |
|--------|--------|
| **A** | Interact |
| **B** | Sword |
| **X** | Map |
| **Y** | Item Use |
| **L** | Previous Item |
| **R** | Next Item |
| **Start** | Pause |
| **Select** | Select |
| **D-pad** | Movement |

## Shortcuts and Functions

These are keyboard shortcuts for things outside the game itself, such as saving and loading save states, pausing, resetting, toggling fullscreen, and turbo. You can rebind each of them to whatever key you prefer. Defaults are just starting points. One exception is **Esc**, which opens the menu and can't be rebound.

## Cheats

Cheats are optional bindings for actions like restore health, restore equipment, give all keys, and walk through walls. They have no keys assigned by default, and you bind them the same way as anything else.

## Connected Devices

This panel lists the keyboards and controllers the app has detected. Each entry shows the device name and, when it can be identified, a matching preset.

You can apply a controller preset such as **Xbox**, **PlayStation**, or **Switch Pro** to fill in a full set of mappings at once. Applying a preset overwrites the current bindings, so use it as a fresh starting point rather than a tweak. You can also assign a device to a profile so it's tied to that layout.

Stick and trigger calibration lives in [Controller Calibration](controller-calibration.md), and rumble settings are in [Haptics](haptics.md).
