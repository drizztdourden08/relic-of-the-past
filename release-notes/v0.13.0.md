# Relic of the Past v0.13.0

## Features

- Detects your display's refresh rate and shows it next to the FPS counter. If it's not a multiple of 60, scrolling can look uneven, so a red "incompatible refresh rate" tag appears, and clicking it opens the setting to fix it.
- New "Set Synced Refresh Rate in full screen" option under Display, plus a "Change refresh rate" button to set one permanently.
- Android now hints its intended frame rate to the system for a better display mode match.
- About page debug info now includes host hardware, monitors, and audio devices.
- Open a profile's folder straight from its Home tab.

## Fixes

- Custom player sprites no longer recolor villagers and other characters.
- The second dungeon's boss is no longer invisible in widescreen.
- Fixed crystal layout and sprite proportions on the widescreen pause screen.

## Changes

- Removed the System tab. Window and performance settings moved to Display; save states moved to Gameplay.
