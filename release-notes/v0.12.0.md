# Relic of the Past v0.12.0

## Features

- Boot splash with a progress bar while the game core loads, so startup no longer looks frozen.
- New "auto skip dialog" option.
- The navigation widget, minimap and overlay now show what the reachability pass knows about a screen.

## Fixes

- Custom player sprites now use their own colors instead of the stock palette, and switching sprite applies right away rather than on the next launch.
- Sprite picker previews were showing the wrong colors.
- Removed a glitch-only room from the map data and pointed the first castle's secret passage at the right hole.
