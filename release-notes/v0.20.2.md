# Relic of the Past v0.20.2

Checks tracker rebuild, widget state in the profile, multiworld pool icons, and a one volley wishing pond.

## Checks tracker

- Summary and filters in one header band above the list, pinned by a new Checks widget setting, on by default.
- Card grid takes its column count from the width it has. Cards are the default view.
- Status marks are SVG icons, one set across the summary, the filter buttons and the rows.
- Design-system controls throughout: segmented controls, tag picker, progress bar, buttons.

## Randomizer

- Pool icons: one per game an Archipelago pool can hold. Efracrafting drew the 12 Zelda icons and the Archipelago mark that covers every other game.
- Redrawn quiver icon, and a Randomizer Item Icons credits section for Efracrafting.
- The wishing pond pays its whole amount in one volley, a gem per denomination, the fairy rising after the last splash.
- Fixed the pond slot names, and one check per upgrade.
- The floodgate and the flute activation spot complete from real game state.
- Loading a profile resets the randomizer session.
- Fixed the dungeon freeze and the cutscene glitch.

## Widgets

- Widget state is kept in the profile: tab, filter, open panels, expanded groups, view modes, search, navigation and simulator settings.
- Inventory view mode is per profile.

## Debug reports

- A new interface to choose which recordings to send.
- A recording is marked sent when its upload succeeds.
- Installs the latest ffmpeg release.
