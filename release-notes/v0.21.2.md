# Relic of the Past v0.21.2

This release adds Archipelia lobby play, publishes the Archipelago world for Archipelia, moves the app onto the latest Brock and Tessera foundation and rebuilds the Controllers page.

## New

- Profile creation has an Archipelia mode with Local, LAN and Remote lobbies, a lobby code and address, and joining on Create. A waiting profile shows its state and has a single Delete.
- DeathLink is a randomizer option. It is hidden in Local mode.
- The Archipelago world is published with each release for Archipelia, built for Archipelago 0.6.6, 0.6.7 and 0.6.8, with an index and a verifiable build attestation beside every file.
- The Archipelia mode is available without Experimental Features. Archipelago online play stays behind them.

## Controllers

- The Controllers page is rebuilt on the shared Brock controller hub, with a Directory, connected pads, logs and diagnostics, and a live pad overlay with labelled callouts. It now opens from Advanced instead of the top switcher.
- The d-pad uses the original cross glyph, and the SNES Select and Start glyphs are centred in their pills.

## Around the app

- The Data Inspector list table fills its pane and scrolls inside it, and the list pane folds like the detail pane.
- In-app text is trimmed: intro captions, development-state notices and mechanism text are removed.
- The update dialog stays within the window.

## Under the hood

- The app moves to Brock 0.99.0 and Tessera 0.66.0.

## Fixes

- Sprite and asset extraction no longer fail with a "document is not defined" error.
- A bad slot name in the Archipelia lobby is shown as a field error instead of an exception.
- Controller lists are read from the snapshot the main process pushes instead of re-listing every 2 seconds.
