# Relic of the Past v0.10.0

## New features

- Widescreen goes much wider — up to about 32:9, drawing the real surrounding map instead of stopping at the old 512px edge.
- Tall-screen rendering for displays taller than 4:3.
- The camera locks to your viewport so wide/tall views rest on the area edge — no black bars or garbage at the borders.
- Smooth screen-to-screen transitions across the wider view.
- Sprites show up properly across the whole wide view — no more ghost duplicates or pop-in, and off-screen enemies stop acting from off-screen.
- Custom Link sprites: import `.zspr` files in the Data Manager and pick one per profile.
- Separate Music and SFX volume (opt-in).
- Bug fixes are now 42 individual toggles instead of three big switches — turn on exactly the ones you want.
- Settings reorganised into tabs: Display, Graphics, Bug Fixes, Audio, HUD, Gameplay, System and Mobile.

## Under the hood

- Save states no longer break when you change settings — a one-byte audio setting was leaking into the save layout and crashing old saves on load. Fixed, and the format is locked down so it can't happen again.
- Everything that differs from the original is opt-in and gated in C, so with all toggles off the game is byte-for-byte vanilla.
- The 42 bug-fix flags are generated from a single catalog, so the C side and the UI can't drift apart.
- The wide overworld uses a new linear world tilemap, allocated only when needed (4:3 builds pay nothing) and with a safe fallback if memory runs out.
- The audio engine recovers instead of hard-crashing if it hits an unimplemented command after a load.
- Widescreen sprite and shadow-alignment fixes.
- Cleaned up various compiler warnings in the game core build.
