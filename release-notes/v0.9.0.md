# Relic of the Past v0.9.0

The app now runs on Android & fix a bunch of inherent platform/OS issues

## Under the hood

The largest part of the release, even if most of it is invisible while you play.

- Instead of hardcoding stuff for platform and OS, I've trickle down the architeture to detect "capacities". That means detecting for example that the device has touch capabilities, the size of the screen, etc...
- Using the above, I change certain behavior like the left and right menu on swiping the side (instead of the title on non-touch)
- The app was reorganised around a platform layer so one game core runs under both wrappers — Electron on desktop, Capacitor on Android.
- All storage moved onto a per-OS file store — profiles, saves, sessions, ROMs, languages, MSU and sprites — which is what makes the new Data Manager possible.
- The game core build was unified into a single cross-platform script, so it can't drift between platforms.
- Releases now build and ship Windows, macOS, Linux and Signed Android builds together from one pipeline.

## Android

Powered by Capacitor and using the plugins it provides:
- forced landscape, edge-to-edge, audio, and the screen stays awake while you play.
- Touch controls — edge drawers for the options we usually have in titlebar (right) and to replace "ESC" (left)
- Full-bleed rendering that draws into the notch.
- A notch render mode so you can choose how the screen sits around a cutout.

## Controllers

- Linux support, with udev rules and a `.deb` installer so pads work without extra setup.
- Native controller support on Android (To a certain extent. There's limitation in BT)

## Screen & aspect ratio

- New aspect ratio settings: Auto, Screen, Preset or Custom.
- Widescreen is capped to the SNES's real 512px limit, so the edges no longer show garbage on large areas.
- Can only support 19:9 for now maximum. Working on getting more but that requires modifying the PPU so that's going to be separate.

## Save states

- Redesigned slots and a scrollable overlay.

## Around the app

- The Data Manager is the new home screen (When there is no data yet), replacing the legacy profile picker.
- Responsive layouts for small screens — phones, and small desktop windows too.
- Asset extraction runs in the background now, so the UI no longer freezes while building from your ROM.
- The About page is a full screen with a copy-debug-info button (To hlep on openeinng issue here), but remain dialog size.

## Fixes

- Linux: the game shows even when a WebGL cross-context read fails.
- The original HUD no longer shows through the enhanced overlay during the intro.
