# Relic of the Past v0.8.3

This is the first public release for Relic to the Past with wiki, and website going live at the same time we're posting this on Reddit.

## Highlights

The two weeks since v0.8.2 went mostly into the navigation/pathfinding engine (still in active development), a large internal refactor for long-term maintainability, and hardening the project for public contribution. The app remains fully playable, with the groundwork for randomizer support coming together under the hood.

## Navigation & Logic (in development)

The pathfinding and minimap system saw the most work this cycle. It's **not final yet**, but the engine is substantially more accurate:

- **Indoor dungeon minimap** — full-room rendering with correct dungeon-map positioning
- **Layer-aware A\* pathfinding** — routes now respect map layers and ledge/exit constraints
- **Proper 2×2 body-position BFS** — replaces the old clearance-based approach for accurate traversal
- **ROM entrance database** — entrances now come from real ROM data instead of tile-scanning
- **Richer tile classification** — stairs, water staircases, swap-layer stairs, and ledges (incl. bidirectional ledge handling)
- **Flood-fill correctness** — propagation constrained to the correct big-screen group; interior navigation and entrance-marker alignment fixes
- **Analysis pipeline scaffolding** — global-flood, entrance-resolver, requirement-detector, region-updater, and connection-updater stubs toward automated logic

## Under the Hood

A major code-quality pass to keep the project maintainable as it grows:

- **Design-system migration** — navigation, dialogs, editors, and overlays rebuilt on shared DS primitives; new shared `NavRail`, `WindowHeader`, `SideNav`, and `SettingsShell`; all inline/raw colors tokenized
- **Modular architecture** — large files decomposed into focused modules (navigation, flood-fill, shadow editor, screen/connection editors, Electron main, and the game bridge), all within the ≤200-line standard
- **Type safety** — `tsc` driven to zero errors with real bug fixes and dead-code removal
- **Design Gallery** rebuilt as a storybook on top of the design system

## UI & Design Polish

- **Sprite Debug** is now a full-window page (closes on Esc, tabbed)
- Consistent gold/green active-and-hover states across side menus and headers
- HUD, logs, and navigation-overlay layout/readability tweaks

## Build & Packaging

- **Automatic setup** — the WebAssembly core is built and the Electron binary fetched automatically on `dev`/`build`; no manual steps for contributors
- **On-demand CI** — quality checks run on pull requests and manual dispatch (no noisy auto-runs); releases build on a version tag
- More resilient dependency install in CI and release pipelines

## Project & Release Hardening

- Added **LICENSE**, a proper **README** (with disclaimer + badges), `CONTRIBUTING`, `SECURITY`, and issue/PR templates
- **Copyright/media gate** — an automatic guard blocks commits and PRs that add media or Nintendo references unless explicitly approved by the maintainer
- Documentation reorganized (getting-started, architecture, user-guide, contributing, hooks) and published to the project Wiki
- Credits and attribution updates (e.g., game-icons.net)

## Fixes

Dozens of fixes across navigation, layering, HUD sprite rendering, widgets, and design tokens — see the commit history for the full list.
