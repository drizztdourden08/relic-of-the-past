# Relic of the Past v0.21.0

This pre-release adds optional experimental play and HUD tools, expanded data tools, Hookshop and Sanctuary work, and a rebuilt app interface.

## New

- Play a randomized seed in an Archipelago multiworld.
- A new Randomizer page brings seed options together. Progressive items appear as sprite ladders, and Progressive Ocarina joins the pool options.
- Story events and their tracker records now share one dataset. Tracker fixes from play testing improve how progress is reported, and story events no longer appear as ordinary pool items.
- The GBA page has a filterable advancement tracker and clearer progress states. This work remains experimental.
- Modern Controls adds game actions beyond the original SNES buttons. Vanilla Controls keeps its own focused button mappings.
- Build a custom HUD with the layout editor. A countdown timer can appear in Enhanced and Modern HUD layouts, with pixel and smooth styles.

## View

- A redesigned Home screen adds section navigation and settings search. Game pages use the title scene behind their headers, and Data has a more compact overview.
- The reimagined title screen includes efracrafting's fighter sword. Title and opening story artwork can be extracted from the ROM.
- The Original picture size is available alongside fixed aspect ratios, with the HUD and display settings following the selected view.
- Controls has clearer Options, Profiles, and Devices areas. The side panels can fold, resize, and remember their widths.
- Character, Language, and MSU Studios have been rebuilt around lists, larger work areas, compact toolbars, and side panels that can fold or resize.

## Settings

- Contributing now calls its developer switch Developer Mode. Turn on Developer Mode, then Experimental Features, to use Archipelago online play, Modern HUD and controls, the HUD Layout Editor, and GBA settings. Turning Experimental Features off switches Modern HUD and the extra dungeon off and disconnects an active Archipelago session.

## Around the app

- Importing a ROM can extract its sprites at the same time. The Sprites page also offers extraction for ROMs that already have assets.
- Profile details now have tabs, editable fields, and access to their settings.
- Language extraction identifies supported releases from the ROM itself.
- Hookshop introduces a community store experience for browsing and installing packs, with account sign-in and clearer install status.
- Packs installed from Hookshop show their origin and are protected from direct editing. Where the licence allows it, Duplicate makes an editable copy.
- Store publishing gains picture cropping, background uploads, resumable progress, version history, and a review flow.
- Sanctuary adds contributor sign-in, file sharing, bug reports, file versions, group rights, and review actions.
- Saves and Auto-saves have clearer rows with full screenshots, in-place renaming, and Load, Overwrite, and Delete actions that ask for a second press. Quick saves retain their card layout.
- Developer tools have been reorganized as widgets. The Shadow Editor is a kit; the data inspector, game state, music debugger, navigation, simulator, and logs are separate tools.
- Bug reports can include recordings, show a receipt, and be retried. Debug files are attached only when debug logging is enabled.

## Under the hood

- The desktop app, websites, workflows, and shared code have moved to Brock and Tessera. The migration keeps existing on-disk save and game formats.

## Fixes

- Deleting the active profile stops its game and selects another profile before removing it, so Home remains reachable.
