# Relic of the Past v0.17.1

The Linux AppImage launches again.

## Linux

- The AppImage would not start on any release after 0.15.2. It was packed with a
  compression format its own runtime cannot read, so it failed to mount before the
  app ever got a chance to run. It now uses a format the runtime supports, and comes
  out slightly smaller too.
- The Debian package was never affected.
