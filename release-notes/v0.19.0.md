# Relic of the Past v0.19.0

Three new studios: language, audio and player sprite. Sprite extraction works again.

## Sprite extraction

- Sprite extraction produced no files in v0.17.0, v0.17.1 and v0.18.0. It reported success and wrote nothing.
- The extraction data was missing from those builds. Nothing was wrong with the ROM.
- Extracting on one of those versions also deleted sprites extracted on v0.16 or earlier. Extract again to restore them.
- A release built without that data now fails instead of shipping.

## Language Studio

- Language packs can now be edited, not just extracted: the dialogue, a glossary, and the item names in the pause menu, all kept as plain files.
- The dialogue editor works one line at a time, the same way the text box does. The margin shows the row number, how much room is left on the line, and the character count.
- Every character is measured at the width the game will actually draw it, so a line that looks like it fits does fit.
- Saving is blocked while a line is too long. The game never wraps text, and a long line paints over the line below it.
- Pauses and line breaks show as markers in the margin instead of tags mixed into the text.
- Ten entries the game uses for its own yes/no prompts cannot be edited. Changing one breaks every prompt in the game.

## Audio replacement

- Background sounds and sound effects can be replaced now, not just music. Anything a pack leaves alone keeps playing from the game.
- One track can hold several sounds at once, each with its own timing: played once, looped, or at random intervals. Looping wind with the odd gust over it, for example.
- New pack file (`.msul`) and a studio for building and previewing packs. It is a zip underneath, so any archive tool can open it.
- A pack carries its own settings, so there is nothing to set up after importing one.
- The game's original sound can be played next to a replacement, without disturbing the game or a save.
- Every sound in the game is listed by name.
- Music now changes when it should. It used to stay put when crossing between two areas that share the same original track, when entering a building, when loading a save state, and after respawning.

## Player Sprite Studio

- A gallery of every state the game can draw the player in: 40 actions, in every direction.
- Colours can be edited for the four outfits and both gloves, limited to the colours the console can actually show.
- Changes are kept separately from the original, so Revert always puts it back exactly.
- Community `.zspr` sheets import and export unchanged.
- A new `.rsp` file saves the sheet and the colour changes together, so a recolour survives closing and reopening.
- A new sprite can start from the game's own player sheet, read out of the ROM.

## Saves

- Import Save on the Home tab brings a save from another emulator (such as a Snes9x `.srm`) into a profile. It is checked against the game's own save check first.
- Deleting a custom sprite now clears it from every profile that used it. A running game wearing it goes back to the original sprite.

## Fixes

- The running man can outrun a wide view. His run was a fixed set of frames sized for the original screen, so he stopped short of the fence and could stall partway.
- Muting now silences everything. Sound could still come through while the control showed muted.
