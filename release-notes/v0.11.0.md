# Relic of the Past v0.11.0

## Features

- Input is now tied to your controller profile — only the controller a profile is configured for drives the game, so an unassigned pad no longer controls it.
- Switch input profiles on the fly with Page Up / Page Down, with a new on-screen profile switcher.
- Per-device haptics — choose which connected controllers rumble.
- The controller-disconnect overlay now shows instantly (including at startup when the right controller isn't connected), lists the actual bound shortcuts, and lets you switch profiles to recover.

## Fixes

- Rumble now correctly turns on and off from the Haptics setting.
- Navigation reachability fixes — dual-layer maps, ledge crossings, and 1-wide ledges.
