# Relic of the Past v0.12.1

## Features

- New V-Sync option under Settings > Performance. It paces the game against your display's refresh rate instead of an internal timer, which smooths out scrolling on 60 Hz screens where the two would otherwise drift apart. Game speed stays correct on any refresh rate, and the setting can be toggled while you are playing.
- New Pixel Perfect option under Settings > Window, available when the viewport is set to Letterbox. It scales the picture by whole pixels only, so every pixel comes out exactly the same size. This removes the shimmer that runs across fences, walls and other straight edges while the screen scrolls, at the cost of slightly wider black borders. Linear Filtering is turned off while it is active.

## Changes

- Removed the "Disable Frame Delay" setting. It only ever applied to a build of the game core that this app does not use, so it had no effect here.
