# Relic of the Past v0.19.2

This update restores pre-release versions in the in-app version picker.

## Updates

- When **Include pre-releases** is enabled, the picker once again lists published 0.20 test builds alongside stable versions.
- The update notification now uses the same version list as the picker, so it can offer a newer pre-release even when a stable hotfix was published more recently.
