# Relic of the Past v0.8.4

## In-game language switching

- Picking a language on a profile now actually changes the dialogue language in-game, not just the label.
- Asset blobs bundle every extracted language pack (US always included), and the game loads the one you picked.
- Redesigned **Languages** inspector with **Font** and **Dialogue** tabs — view the glyph sheet and browse dialogue lines with control codes shown as chips.
- Note: re-extract older language packs (re-drop the ROM) so they include the font data this needs.

## Enhanced HUD fixes

- HUD sprites are now bound to the active ROM.
- Vanilla HUD locks itself when sprites are missing instead of breaking.
- HUD visibility is gated by the current game mode.

## Fixes

- Controller button images now load correctly in the packaged app (broken absolute paths under `file://`).
