# Relic of the Past v0.22.0

This pre-release translates the whole app into ten languages, plays the French, German and Japanese cartridges with their own screens, and imports fan translations.

## New

- The app is available in English, French, German, Italian, Spanish, Portuguese, Polish, Dutch, Swedish and Japanese, chosen in Settings, with a per-profile override in the profile editor.
- Dates, check names, screen names, item names and place names follow the app language.
- Text drawn in the game view (prompts, controller and HUD notices, save hints) follows the profile's ROM language.
- Japanese cartridges play with their own dialogue, file select, kana name entry, pause menu, map labels, ending and credits, drawn with a Japanese face that carries the kana and the kanji the game uses.
- The Original title can run the Japanese title sequence, chosen as US or Japanese in Settings.
- Japanese text needs the Japanese sprites: a Japanese language stays locked until they are imported.
- French, Canadian French and German cartridges show their own file select, name entry, copy and erase screens, pause boxes, dungeon map, life label, ending and credits.
- The Europe ROM is a language set, and any non-USA ROM plays its language on top of the USA ROM.
- Fan-translated ROMs import as languages in the Language Studio, with a report of what was found, a tab to name letters the import could not read, and the original licence and credits kept with the set.
- Dialogue draws every accented Latin letter, each one a setting that is on by default.

## Changes

- ROMs, Sprites, Profiles and the Character, MSU and Language studios create new entries through a New button and a step-by-step wizard.
- Every upload offers a file or a web link, and a ROM upload checks the ROM as soon as it is dropped, with the supported ROMs listed under it.
- Importing a ROM keeps its language as a language set, and language sets show whether they come from a cartridge, a patch or your own edits.
- The dialogue font size slider has two smaller steps.

## Fixes

- A save state loaded on the file select redraws it in the current language and pack.
- A held press on the Japanese name entry no longer skips a row when the page turns.
