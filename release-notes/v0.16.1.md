# Relic of the Past v0.16.1

Fixes the downloads that v0.16.0 got wrong.

## Windows

- The installer is now the small download it was meant to be, well under a megabyte. It fetches the app itself, so the file never goes stale. v0.16.0 shipped the whole app in the installer by mistake.
- There is one Windows download now instead of two. If you want the app somewhere other than the default location, the installer asks on its first screen.

## Linux

- The AppImage download link works again. It has been pointing at a filename that was never published.

## Keeping your files beside the app

- Still supported, and no longer needs a separate download: create a folder named `data` next to `Update.exe` in the installation folder and everything of yours is kept there. See the Portable Mode page.
