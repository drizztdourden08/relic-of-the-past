# Relic of the Past v0.8.5

## Controllers

- Added support for the **Nintendo SNES Controller (NSO)** — the wireless SNES pad for Switch Online now works out of the box, including its extra ZL/ZR buttons.
- Fixed a freeze where holding or mashing a button (like charging a spin attack) briefly locked movement on controllers that don't rumble. The game was sending vibration to pads that can't use it; it now only goes to controllers that support it.
- Button icons now line up with the right buttons in the controls screen, and each controller uses its own button names.

## Fixes

- Hid an unfinished navigation banner that could appear during play.
