# Relic of the Past v0.16.0

A new installer, and updates that look after themselves.

## Installing on Windows

- The download is now a small setup, well under a megabyte, that fetches the app for you. It never goes stale: a copy you downloaded months ago still installs the current version.
- It installs for your user account, so there is no admin prompt, and it starts the app when it finishes.
- If you would rather put it somewhere else, such as another drive, the first screen offers that.
- The separate portable download is gone. You can still keep your files beside the app: create a folder named `data` next to `Update.exe` and everything of yours is written there. See the Portable Mode page.

## Updating

- Accepting an update downloads it, installs it and restarts the app on its own. There is no wizard and nothing to click through.
- Only what changed is downloaded, so a typical update is a few tens of kilobytes instead of the whole app.
- The update window lists every version, tells you what each one will actually download, and lets you go back to an earlier build if something stops working.
- Pre-releases are off unless you ask for them, and that choice is remembered.
- Windows and Linux update in place. On macOS the button opens the release page instead, because those builds are not signed by Apple.

## Starting up

- The wait before the app appears now has its own small window, and the main window appears already finished instead of assembling itself in front of you.

## Fixes

- The Linux AppImage download works again. It had been pointing at a filename that was never published.
- Windows now reports the app's installed size correctly under Settings, Apps.
- The app is a noticeably smaller download after dropping graphics libraries and language files it never used.
