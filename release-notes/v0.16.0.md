# Relic of the Past v0.16.0

A new installer, and updates that get out of your way.

## Installing

- The Windows download is now a small setup that fetches the app for you, so it always installs the current version no matter how old the file you downloaded is.
- It installs for your user account, with no admin prompt, and starts the app when it finishes.
- The portable build keeps its settings, saves and imported files inside its own folder. Put it on a USB drive, move it to another machine, and it picks up exactly where it left off.

## Updating

- Accepting an update now downloads it, installs it and restarts the app on its own. There is no wizard and nothing to click through.
- You can pick an older version from the update window if you need to go back.
- Windows and Linux update in place. On macOS the button opens the release page instead, because those builds are not signed by Apple.

## Smaller

- The app download is noticeably smaller after dropping graphics libraries and language files it never used.
