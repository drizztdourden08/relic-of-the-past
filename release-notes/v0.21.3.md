# Relic of the Past v0.21.3

This pre-release brings full touch controls to the Android app, with a layout editor, portrait play and smoother performance on phones.

## New

- Full-screen touch controls with a dynamic or fixed stick or a D-pad, transparent buttons and a long hold that opens the menu.
- A touch layout editor for each orientation. It opens without a game running, saves every change, adds the face buttons and D-pad as ready groups and drags locked groups as one.
- Snap to grid in the layout editor mirrors from each side, shows the mirror lines and shows which side a dragged piece snaps from.
- Touch inputs can be rebound from a touch bindings table, with a Touch here picker in the rebind popover.
- A Controller Profile menu switches controller profiles during play.
- Touch vibration has a strength slider.

## Changes

- The phone app turns to portrait, and the phone's orientation follows the aspect choice.
- Picture has an Alignment setting for the picture and its overlays.
- The tall view reaches as high as the wide view reaches wide, with 9:32 when ultrawide is on.
- Phones run the game at 60 Hz, which removes the lag and crackling audio in heavy scenes such as rain.
- The controls screen fits narrow screens: the tabs fold, the settings sit in two columns and the tables scroll sideways.
- The clear button stays visible on phones.

## Fixes

- Back on the phone returns to the menu or home instead of quitting the app.
- Saving and loading a state work on the phone, and loading a save goes straight back to the game.
- A save the game cannot load is refused before the game starts.
- A quick tap stays pressed long enough for the game to read it.
- The touch pad no longer triggers the controller disconnected pause.
- Changing touch controls no longer asks for a game restart.
