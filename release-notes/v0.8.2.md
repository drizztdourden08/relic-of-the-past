# Relic of the Past v0.8.2 — Pre-Public Build

A modern desktop wrapper for the A Link to the Past PC port, built to make the experience accessible, polished, and ready for randomizer support.

> **Important:** This application does not contain any copyrighted material. You must provide your own ROM file.

---

## Highlights

This is the first packaged release. The app is fully functional and playable, with extensive quality-of-life improvements over the original PC port.

---

## Features

### Core
- **Electron + React + WebAssembly** — the original C port compiled to WASM, wrapped in a modern desktop app
- **No Python required** — asset extraction rewritten entirely in TypeScript
- **Cross-platform** — Windows, macOS, and Linux builds
- **Profiles** — isolated containers with their own ROM, language, MSU pack, save data, settings, and control bindings

### Game Settings (all configurable in-app, no more .ini editing)
- All original PC port settings
- Aspect ratio options (including 3:2)
- Window modes: fullscreen, borderless, with autofit/stretch
- FPS display

### Enhancements
- **Edge effect** — mirrored & blurred animation on world borders for immersion (no black bars)
- **Interior background** — dark background inside houses instead of brown void

### Audio
- Full MSU support with in-app import and management
- Independent music, SFX, and master volume controls
- Mute toggle in title bar

### Saves
- **Auto-save** with configurable timer + save-on-quit
- **Quick saves** — slide-down UI showing all slots, or direct shortcut with configurable hold duration
- **Normal saves** — named saves without shortcut risk of accidental overwrite
- **Save state screenshots** — visual preview of each slot

### HUD
- Choice between original and enhanced HUD overlay
- Enhanced HUD respects aspect ratio for proper placement
- Smoother heart and magic meter animations
- Game sprites extracted and rendered as a React overlay (the real HUD is hidden underneath)

### Haptics
- Vibration events for sword swings, hookshot impacts, damage, boss kills, locked doors, item pickups, and more
- Per-event toggle in settings
- Supported on Switch Pro Controller, Xbox controllers, and more

### Input
- **Supported devices:** Switch Pro Controller (v1 & v2), GameCube wireless, Xbox, PlayStation (DS3–DualSense), 8BitDo, keyboard
- Full rebinding of any action to any key, button, or axis
- Built-in input calibration tool (byte inspector, vibration tester, input recording)
- Controller icon sets for all supported devices

### Widgets (in-game overlays)
- Dock to any edge or float freely, resizable, adjustable transparency
- **Inventory Tracker** — shows all owned items in configurable layouts
- **Checks Tracker** — 257 checks with status, grouping, and filtering
- **Logs** — real-time app log viewer
- **Location & Navigation** — current screen info and connections (WIP)
- **Cheats** — give items, fill bottles, adjust health/magic/rupees/ammo

### Navigation & Logic (foundations for randomizer)
- Full pathfinding with item requirements across overworld screens
- Tile-level route planning through actual map collision data
- Datasets: all regions, connections, items, and checks

### Developer Tools
- Sprite debug viewer
- Connection overlay for overworld connectivity review

## Getting Started

1. Download the appropriate file for your platform
2. Launch the app
3. Import your ROM in the data management interface
4. Create a profile, configure your preferences and play

---

## Known Limitations
- macOS and Linux builds are untested (first release)
- Navigation/randomizer logic is foundational — not yet user-facing beyond the widget
- No code signing — your OS may show an "unknown publisher" warning on first launch
